# 应用管理页列宽度自适应

## 任务描述
将应用管理页的应用名称列和封面列从固定像素宽度改为百分比宽度，实现自适应布局

## 上下文信息
- **技术栈**：Vue 3.5 + TypeScript + Ant Design Vue 4.2.6
- **目标文件**：`yu-ai-code-mother-frontend/src/pages/AppManagePage.vue`
- **创建时间**：2026-03-30 23:32:23

## 当前状态
- 应用名称列：width: 300 (固定像素)
- 封面列：width: 150 (固定像素)

## 目标状态
- 应用名称列：width: '25%' (百分比宽度)
- 封面列：width: '15%' (百分比宽度)

## 执行步骤

### 步骤 1：读取目标文件
- **文件**：`yu-ai-code-mother-frontend/src/pages/AppManagePage.vue`
- **目的**：确认当前代码状态
- **预期结果**：获取完整的文件内容

### 步骤 2：修改应用名称列宽度
- **位置**：第 98 行
- **修改前**：`{ title: '应用名称', dataIndex: 'appName', key: 'appName', width: 300 }`
- **修改后**：`{ title: '应用名称', dataIndex: 'appName', key: 'appName', width: '25%' }`
- **预期结果**：应用名称列使用 25% 的相对宽度

### 步骤 3：修改封面列宽度
- **位置**：第 99 行
- **修改前**：`{ title: '封面', key: 'cover', width: 150 }`
- **修改后**：`{ title: '封面', key: 'cover', width: '15%' }`
- **预期结果**：封面列使用 15% 的相对宽度

### 步骤 4：验证修改
- **操作**：重新读取文件确认修改正确
- **预期结果**：确认两处修改都已生效

## 设计说明
- **方案选择**：方案 3 - 使用百分比宽度实现自适应布局
- **优势**：
  - 响应式设计，适应不同屏幕尺寸
  - 更好的用户体验
  - 符合现代 Web 开发最佳实践
- **注意事项**：
  - 百分比宽度在极小屏幕上可能仍显拥挤
  - 建议配合表格的 scroll 属性使用（如需要）

## 验收标准
1. 应用名称列宽度设置为 '25%'
2. 封面列宽度设置为 '15%'
3. 代码语法正确，无 TypeScript 错误
4. 页面渲染正常，列宽自适应

## 后续建议
- 如需在小屏幕上优化，可考虑使用 `scroll={{ x: 1200 }}` 启用横向滚动
- 可根据实际使用情况调整百分比数值
